---
name: MetricFlow visual system
description: The approved product-wide visual direction for future MetricFlow UI work.
---

MetricFlow uses a dark instrument-panel visual system: Signal Blue is the sole routine interactive color; green, amber, and coral communicate status; violet is reserved for focused data emphasis. Headings, labels, and navigation use a compact display voice, while dense body copy and operational data prioritize readability.

**Why:** The product direction was explicitly approved for application across every MetricFlow screen, replacing mixed default palette choices with clear functional color and a consistent SaaS operations feel.

**How to apply:** New MetricFlow UI should use semantic roles for status and interaction, preserve modest geometry and elevation, use tabular numerals for metrics, and avoid introducing literal palette colors or decorative animation.
